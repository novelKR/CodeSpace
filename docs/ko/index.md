# CodeSpace 문서

[English](../index.md) | [한국어](index.md)

CodeSpace는 개인용 실행 도구 MCP 서버입니다. 바깥 클라이언트가 무엇을
할지 판단합니다. 이 프로세스는 모델을 호출하지 않습니다. 파일을 읽고,
Codex 형식 패치를 적용하며, 등록된 워크스페이스에서 관리형 명령을
실행합니다.
